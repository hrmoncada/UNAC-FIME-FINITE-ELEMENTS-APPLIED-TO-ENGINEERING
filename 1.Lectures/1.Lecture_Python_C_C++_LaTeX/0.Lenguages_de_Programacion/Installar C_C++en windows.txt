How to install GNU GCC 64 compiler for C languages

To install the GNU GCC 64 compiler for C languages on Windows, follow these steps:

Download MinGW: Visit the MinGW-w64 website and download the installer for your Windows version.
Run the Installer: Execute the downloaded file and select the installation directory.

Configure PATH: Open the System Properties, go to Advanced System Settings, and add the MinGW bin directory to the PATH environment variable.
Verify Installation: Open the Command Prompt and type gcc --version to check if GCC is installed correctly.

For Linux and macOS, the installation process is similar, with Homebrew being the preferred method for macOS users
