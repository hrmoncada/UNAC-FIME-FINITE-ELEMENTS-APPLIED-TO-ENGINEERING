INSTALL LINUX
Linux :There is a Linux version at launchpad that can be used on Ubuntu and Debian based systems:

$ sudo apt-add-repository ppa:elmer-csc-ubuntu/elmer-csc-ppa
$ sudo apt-get update

ElmerFEM suite without ElmerGUI
$ sudo apt-get install elmerfem-csc

ElmerFEM suite with ElmerGUI (pick this one)
$ sudo apt-get install elmerfem-csc-eg

Also you can try to install using Ubuntu Synaptic
